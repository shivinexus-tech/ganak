# Vedic interpretation knowledge base

Standing source for the answer-first Chart reading (`src/data/life-interpretation.ts`).
Traits are **synthesised from many sources in original wording** and cross-checked, then
distilled into the card copy. This file is the durable reference; the copy is derived from it.

## Sourcing method
- **Primary citation stays classical** — Brihat Parashara Hora Shastra + Phaladeepika — because
  the core nakshatra/rashi temperament traits are classical lore.
- **Secondary layer = the written footprint of popular modern teachers** (KRS / Kapiel Raaj,
  Lunar Astro, Saptarishis, and others) *plus* independent astrology references and Substacks
  that synthesise the same school. Facts are aggregated across **many** sources and expressed
  in original words — never one creator's script copied. This keeps it accurate and copyright-safe.
- **Video transcripts are NOT used** — YouTube captions, transcript services and the timedtext
  API are all blocked from this environment (tested). Where a creator's *unique* insight lives only
  in a video, the owner can paste a few bullets and it gets folded in (synthesised, guarded).
- **How it feeds the product:** the 3–4-line summary card uses the essence; the fuller notes here
  are the seed for the deferred "tap for more" deep view (backlog), where the real depth has room.
- **Extending it:** add sources per placement over time; drop in owner/creator bullets where a
  placement still feels thin. The `validation/life-interpretation-copy.cjs` guard keeps struck-out
  wording from returning.
